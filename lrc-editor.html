How it works

  1. Upload an MP3. If it already has synced or plain lyrics embedded, they're loaded as your starting point.
  2. Each lyric line shows a timestamp. Click a line to select it (this doesn't move playback) — select it, then play the song and hit Enter (or the "Set time for line" button) right when it should start.
  3. Use each line's ▶ button to preview playback from that exact line.
  4. Nudge a line's timing with the −/+ buttons or ←/→ once it's selected.
  5. Use "Insert pause line" to mark instrumental breaks at the current playback position.
  6. When you're done, download the plain .lrc file, or embed the synced lyrics directly into the MP3 and download that.

Along the way

  • Your lyrics and timestamps auto-save in this browser as you work, so an accidental tab close won't lose your progress — you'll just need to re-select the same MP3 file to reattach the audio.
  • See the Shortcuts button (top right) for the full list of keyboard controls.
